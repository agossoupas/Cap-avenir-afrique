Activer les notifications Android

Cette page génère les clés nécessaires directement dans ton navigateur. Elles ne sont envoyées ni à GitHub ni à un autre serveur depuis cette page.

Important : génère les clés une seule fois. Ne partage jamais la clé privée. Ne la colle jamais dans un fichier du site ou dans GitHub.

1. Clé privée VAPID — à garder secrète

2. Jeton de planification — à garder secret

3. Clé publique

Garde ces valeurs dans un endroit sûr avant de fermer cette page. La clé publique pourra être utilisée par l'application ; les deux autres valeurs restent secrètes.

Où enregistrer les secrets Supabase ?

1
Ouvre Supabase → Edge Function Secrets.
2
Ajoute les variables suivantes :

VAPID_PRIVATE_JWK = le contenu complet du champ « Clé privée » (JSON).

PUSH_CRON_TOKEN = le jeton de planification.

VAPID_SUBJECT = https://agossoupas.github.io/Cap-avenir-afrique/

3
Enregistre les secrets. Ne les mets pas dans GitHub, dans le code du site ou dans un message public.

La clé publique sera récupérée automatiquement par l'espace candidat depuis le serveur. Il ne faut pas la coller dans le code.

Après l'enregistrement

Retourne dans ton espace candidat, connecte-toi, active les notifications et utilise « Tester les notifications ». L'automatisation des nouvelles offres nécessite encore l'activation du déclencheur planifié dans la base de données.
